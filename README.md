## The Elite experience

Follow the action and manage your Elite Cricket world without digging through chat messages.

| **The action** | **Your corner** | **Everything else** |
| :--- | :--- | :--- |
| Live match updates | Player profile & statistics | Tournaments & fixtures |
| Upcoming matches & results | Rankings & squads | Trivia & rewards |
| Scorecards & match details | Career progress | Shop & account settings |

> **Same community, same data.** The companion app connects to the existing Elite Cricket backend and Telegram-linked accounts. **Hand-cricket gameplay remains in Telegram**; this is not a separate game or a replacement for the bot.

## Designed for the phone

- **Light & dark appearance** with the Elite Cricket visual identity.
- **Fast navigation** between matches, tournaments, rewards and player information.
- **Live information** that can refresh without losing your place.
- **Telegram account connection** so your Elite identity stays together.
- **In-app settings** for appearance, commentary language and updates.

The experience is being refined across devices; features and availability may change before a stable public release.

3. Open the downloaded APK and follow Android's installation confirmation.

Only install releases you trust. Android may require permission to install apps from the source used to open the APK.

### App updates

The Android app's update experience is designed to check for newer published versions and offer **Download → Install**, with the final installation approved by Android. The same controls are available through **Settings → App Updates** when supported by the installed version.

A GitHub release does **not** silently install itself, and an APK update must be signed with the **same signing certificate** as the app already installed.

## Release information

This repository is intended to host **release notes and distribution assets**, not the full app source code or the Python bot.

For future Android releases:

- Tag each version consistently, for example `v1.0.0`.
- Attach the corresponding signed APK as a release asset.
- Increase Android's `versionCode` for each update.
- Keep the Android package ID **`com.beesh.elite`** and release signing certificate consistent.
- Describe user-facing changes and important installation notes in the release.
